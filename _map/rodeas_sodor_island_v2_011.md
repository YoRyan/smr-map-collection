  go to Rodea. All the new engines, many new industries, and of course the original
  game plot.\n If you have not played before, this is your chance! The industries
  are randomly placed, so every game is different.\nI made some minor changes:\nTo
  keep with the story book aspect of the game, only the Thomas type engines were kept.
  The engines were reworked to reflect the gradual increase in performance. Thomas
  was also given some more prominent role.\nI also changed the time. Instead of the
  original 150 years it is 38 years. This again to be more in line with the story.
  The turns per month is upped to 144 turns per month, but the engine maintenance
  cost was lowered to reflect the change.\nYou will be able to build only masonry
  bridges. Again this is to keep the story book appearance\nPlease note that the AI
  players have to be set to 0 (zero) otherwise the game will crash\n\n\nAs for the
  AI players: it is a marginal error. The game was designed for one player. The scenario
  is a performance based entity. You have certain quotas and time limits to meet,
  not to whack the AI.\nOf course it would be nicer if did not occur.\n\n\n2011 Update
  by Karsten\n\nChanges from the 4.7.2009 SAM version:\n\n- Goods file crashes fixed.\n-
  Random event file crashes fixed.\n- FPK files unpacked. \n\nSelect no (ie zero)
  AI players to avoid a crash at start. \n\nHave fun with Rodea's challenging and
  delightful scenario!"
