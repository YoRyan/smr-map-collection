  \    Initially I could not get it to run on my Windows 10 desktop, so the testing
  was done on my old laptop \nrunning Windows 8.  After completion I loaded it back
  onto my desktop and it ran fine.  Now it did take a \ncouple of attempts to get
  it to start.  I keep getting C++ Runtime errors, but that seems to be par for the
  \ncourse with Windows 10 and my desktop.  Hopefully, if you are running Windows
  10 it will run fine for you.  \nIf you find you get some kind of an error, don't
  give up.  Sometimes it seems like it just takes a few tries \nto get it going, and
  then it will run OK.\n\n     On game play, there are a lot of options on where to
  run track.  If you find you are stuck in Era 1, \ntry another approach.  It can
  be done.  I did a little testing at the Robber Baron level just to make sure \nthat
  you could get the map started.  A few adjustments to the RRT_Difficulty.xml were
  made as a result.\nThere are a number of locales that need to grow before goals
  can be met.  Do not wait too long to get\nthose growing.  It should be noted that
  the game includes a good called Light.  The lighthouses are setup\nas industries
  so that a game save and subsequent load will not make them disappear which would
  happen if\nthey were set up as decorations.  The good light has no value and should
  be ignored.\n\n     I downsized the map quite a bit from what it initially looked
  like.  It originally featured 3 sets of \ntrain cars and a number of additional
  engines.  It was just too heavy.  All version 3 material (train cars\nand diesels)
  have been removed.  I think it runs well now and in a reasonable time frame.  I
  hope you enjoy\nit and find it gives you a challenge.\n\nNORTHERN CALIFORNIA GOODS
